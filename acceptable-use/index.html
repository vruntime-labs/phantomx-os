Acceptable Use & Community Guidelines

These guidelines apply to PhantomX OS and its public project spaces. The current Browser Edition does not provide user accounts, chat, file uploads, or a hosted user-generated-content service.

1. Use the simulator responsibly

  • Keep hacking-themed activities fictional, local, or within systems for which you have explicit authorization.
  • Do not use the project to facilitate unauthorized access, credential theft, malware deployment, disruption, surveillance, or data exfiltration.
  • Do not treat simulated output as evidence about real systems or networks.

2. Protect sensitive information

  • Never enter real credentials, API keys, tokens, private keys, or confidential records into the simulated terminal.
  • Do not post personal data, secrets, or private material in public issues or pull requests.
  • Use the private vulnerability-reporting route on the Security page.

3. Project contributions

  • Be respectful, constructive, and relevant in issues, discussions, and code reviews.
  • Submit work you have the right to contribute and identify third-party code or assets.
  • Do not submit malicious code, hidden tracking, deceptive behavior, or unauthorized access mechanisms.
  • Do not impersonate maintainers or misrepresent project status, security, or capabilities.

4. Scope and enforcement

These are project expectations for public participation. GitHub controls its platform and moderation. Maintainers may close or decline contributions that violate these guidelines using available project controls.

5. Future features

If PhantomX adds uploads, user-generated content, chat, accounts, multiplayer, or hosted services, this policy must be expanded with content rules, reporting routes, moderation, retention disclosures, and abuse controls before launch.
