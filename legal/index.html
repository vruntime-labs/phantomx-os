The terms, disclosures, and project policies governing the PhantomX OS website and browser experience.

IN BRIEF

PhantomX OS is a browser-based cyberdeck launcher and simulation experience, not a real operating system. The current app has no project-operated account system or application backend; GitHub Pages and external asset providers may still process technical request data.

Policy dates and scope are stated in each document.

02 / COOKIES & STORAGE

The current application does not intentionally set first-party analytics or advertising cookies. It uses browser-managed cache storage for application resources. GitHub Pages and external asset providers may process technical request data under their own policies.
