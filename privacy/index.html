Privacy Policy

How the current PhantomX OS website and Browser Edition handle information.

1. Scope

This policy covers the publicly hosted PhantomX OS website and browser application maintained by VRuntime Labs. It does not govern GitHub, third-party websites, or external asset providers, which operate under their own notices.

2. Current application behavior

The source reviewed contains static HTML, CSS and JavaScript; a simulated terminal and in-memory example directory; a service worker using the browser Cache API; a web app manifest; and a CSS background image requested from images.unsplash.com.

The reviewed source does not show a project-operated account system, sign-in flow, analytics SDK, advertising SDK, application backend, cloud account, or synchronization service. The terminal is simulated and does not execute arbitrary host commands; the example filesystem is not persistent user-file storage. This is a source-level description as of 6 November 2026.

3. Hosting and technical request data

The site is hosted using GitHub Pages. GitHub and network infrastructure may process IP address, browser/device details, requested resources, timestamps, and security or diagnostic logs. VRuntime Labs does not operate GitHub Pages infrastructure or receive raw hosting logs through the application. See GitHub's Privacy Statement.

4. Browser storage and offline cache

The service worker stores selected application resources in the browser Cache API for repeat and offline loading. This is browser-managed cache storage, not an application analytics cookie or server-side user profile. The current example virtual filesystem is held in JavaScript memory and is not persistent. You can clear site data, cached resources, and service-worker registrations using browser settings.

5. Information you choose to share

Information submitted in GitHub issues, discussions, or pull requests is handled by GitHub and may be publicly visible. Do not post passwords, tokens, private keys, personal documents, or sensitive information in public project channels. The Browser Edition has no private support form.

6. Cookies and similar technologies

The reviewed application does not intentionally set first-party cookies and contains no project-installed analytics or advertising SDK. Browser Cache API storage is distinct from cookies. GitHub, Unsplash, or infrastructure providers may use cookies on their own services. See the Cookie Policy.

No optional analytics or advertising cookies are currently used by the application, so no cookie-consent banner is displayed. If such technologies are introduced, the policy and consent approach must be reviewed before release.

7. Third-party assets and external links

The stylesheet loads a background image from Unsplash. Its infrastructure may receive technical information such as IP address, browser details, requested asset, and request time. Review Unsplash's Privacy Policy. GitHub and other linked destinations have their own privacy notices.

8. Children's privacy

The current Browser Edition is a publicly accessible general-purpose project and does not knowingly request personal information from children. If you believe a child's personal information has been posted in a public project channel, contact maintainers without reposting it.

9. Security

No website, browser, storage mechanism, or network transmission can be guaranteed completely secure. Keep your browser updated. Do not enter real credentials or sensitive information into simulated terminals or fictional mission interfaces. See the Security Policy.

10. Your choices

You may stop using the site, clear browser data and cached resources, unregister the service worker, restrict third-party asset requests, and use GitHub's account/privacy controls for information submitted there. Blocking Unsplash may prevent the background image from loading.

11. Changes

This policy will be reviewed when application features, hosting, or data practices change. Material changes should be reflected by updating the effective date.

12. Contact

For privacy questions, contact maintainers through the PhantomX OS repository. Do not include sensitive personal information in a public issue.

This document is a project disclosure, not legal advice. Review it against the actual deployment and applicable law before launch or material changes.
