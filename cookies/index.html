Cookie Policy

Cookies and similar technologies used by the current PhantomX OS website.

1. Application cookies

The application source reviewed does not intentionally set first-party cookies and contains no project-installed analytics or advertising SDK.

2. Browser cache and service worker

PhantomX uses the browser Cache API through a service worker to store selected application files for repeat and offline loading. This is browser-managed cache storage, not a cookie. You can clear it through browser site-data controls or unregister the service worker.

3. Third-party requests

The stylesheet requests a background image from images.unsplash.com. GitHub Pages hosts the site. These providers may use their own cookies or similar technologies on their infrastructure or other services. Review Unsplash's privacy notice and GitHub's privacy statement.

4. Consent banner

No optional analytics or advertising cookies are currently used by the application, so no cookie-consent banner is displayed. We will reassess this before adding non-essential cookies, analytics, advertising, or other tracking technologies, and implement consent controls where required by applicable law.

5. Your controls

You can manage cookies, block third-party requests, and clear cached website data using browser settings. Blocking Unsplash may affect the background image but should not prevent the core app shell from loading.

6. Updates and contact

Review this policy whenever the site adds analytics, advertising, embedded content, authentication, or technologies that change browser storage or tracking. Questions may be raised through the project repository.
