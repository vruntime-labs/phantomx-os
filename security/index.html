COORDINATED VULNERABILITY DISCLOSURE

Security Policy

We appreciate responsible reports that help keep PhantomX OS and its users safer.

1. Reporting a vulnerability

Use GitHub's private vulnerability reporting form if enabled for this repository. Do not publish an unpatched vulnerability, exploit code, credentials, or sensitive user data in a public issue.

2. Useful report details

Include the affected page or component, impact, reproduction steps, relevant version or commit, and a safe proof of concept where possible. Do not test systems or accounts you do not own or have permission to assess.

3. Scope and safe harbor

Only test PhantomX OS and explicitly authorized assets. Do not perform denial-of-service testing, social engineering, physical attacks, privacy violations, or destructive testing. Stop if you encounter real personal data or systems outside project scope.

4. Response expectations

This is a small open-source project maintained on a best-effort basis. We cannot guarantee a response time, bounty, or disclosure deadline. Please allow reasonable time to investigate and prepare a fix.

5. Current scope

The Browser Edition is a static client-side application hosted on GitHub Pages. Third-party services such as GitHub Pages and Unsplash have their own reporting processes.

6. Contact

Preferred route: GitHub private vulnerability reporting. Confirm that this option is enabled in repository settings before relying on it as the sole channel.
